# Pickleball League Manager

Tạo cho tôi một ứng dụng web đơn giản để quản lý giải đấu Pickleball bằng tiếng Việt, giao diện hiện đại, trừu tượng, thể thao, đơn giản.
Web gồm các phần:
1. Trang tạo giải: Cho nhập Tên giải đấu, Số lượng sân sẽ vận hành, Tên sân, và Ngày thi đấu.
2. Trang quản lý đội: Cho chọn theo thể thức số người đăng ký sẽ chia ra bốc thăm random dựa trên điểm trình, có ô nhập điểm trình, hay bắt cặp từ đầu với nhau, nhập danh sách VĐV hoặc tên Đội, và có mục chia bảng tự động.
3. Trang thể thức thi đấu: Có nút "chọn thể thức" chia bảng/Loại trực tiếp, vòng tròn, đồng đội.
4. Trang Bảng tỷ số: Nhập điểm số từng trận và tự động cập nhật bảng xếp hạng.
